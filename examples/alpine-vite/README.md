# Alpine Vite example

The first Source Card receives validated supplied `Micah 6:8` `data` through a property and makes no request. Submitting the form clears `data` and assigns the `sref` attribute. Alpine owns draft input, presentation attributes, visible host status, and the canonical selection event; the element owns acquisition and lifecycle. Destroy cleanup disables acquisition and clears owned inputs.

Build the workspace before starting the direct development server:

```powershell
pnpm build
pnpm --filter @sefaria-example/alpine-vite dev
```
