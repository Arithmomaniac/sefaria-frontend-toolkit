# Vanilla Vite example

This private example first validates supplied `Micah 6:8` JSON and assigns it as authoritative Source Card `data` through a property with zero requests. Submitting the form clears `data` and assigns the `sref` attribute; the element owns acquisition, cancellation, stale-result suppression, private preparation, status, and error presentation. The host owns draft input, presentation attributes, canonical readouts, and the explicit activation gate.

Build the workspace before starting the direct development server:

```powershell
pnpm build
pnpm --filter @sefaria-example/vanilla-vite dev
```
